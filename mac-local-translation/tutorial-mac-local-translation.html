✅ 最短命令：wsp test-jp.mp3 → 输出 ~/Whisper/test-jp_双语字幕.srt。首次加载 7B 权重需数十秒，之后有翻译缓存可断点续跑。

2.2 为什么不修 Brew、不装 Ollama

这台是 Intel Mac / macOS 14 Sonoma，Homebrew 7.0 已把 Intel 与 Sonoma 降为 Tier 3——不再产预编译 bottle，brew install ollama 变成 Go 源码本地编译，16G 内存被挤爆，进程被信号 137 掐断。结论：本机用不上 Ollama，llama_cpp 已随 comfy 环境装好，模型文件也早就在位。Brew 原地冻结不卸、不升级。

2.3 依赖获取的两个坑

  • llama-cpp-python 在清华源是 76.6MB 源码包、需本地编译 → 直接复用已装好的 comfy 环境，不要重装。
  • ComfyUI 目录里那颗 qwen2.5-0.5b-instruct-q4_k_m.gguf（469M）是给绘图提示词做中英转换的，翻译质量不合格（实测复读、自问自答），不能拿来做字幕。

3.1 翻译模型（7B GGUF）

DST="$HOME/Whisper/models/Qwen2.5-7B-Instruct-Q4_K_M.gguf"
curl -L --fail --retry 2 --speed-time 30 --speed-limit 500000 \
  -o "${DST}.part" \
  "https://www.modelscope.cn/api/v1/models/lmstudio-community/Qwen2.5-7B-Instruct-GGUF/repo?Revision=master&FilePath=Qwen2.5-7B-Instruct-Q4_K_M.gguf"
mv "${DST}.part" "${DST}"

必须放在 $HOME/Whisper/models/ 且保持这个文件名——那是管线的 MODELS_DIR 默认查找位，放对了就不必写 --gguf-model。

3.2 识别模型（large-v3）

HF_ENDPOINT=https://hf-mirror.com HF_HUB_ENABLE_HF_TRANSFER=1 \
  hf download Systran/faster-whisper-large-v3 \
  --local-dir "$HOME/Whisper/models/faster-whisper-large-v3" \
  --local-dir-use-symlinks False

⚠️ 目录名必须是 faster-whisper-<档位>，管线按前缀硬拼路径。若目录里只有 Downloads/model.bin，需补齐 config.json、preprocessor_config.json（feature_size: 128）、tokenizer.json、vocabulary.json。

3.3 已清理的资产（别再装回来）

  • faster-whisper-small / large-v3-turbo：与 large-v3 同族同功能，收敛到单档。
  • Qwen 0.5B GGUF：实测复读、自问自答，翻译不合格。
  • 本机 NLLB-200：蒸馏版会丢人名，服务器留完整副本做兜底即可。

四、核心改造与启动器

4.1 给管线加一颗 gguf 后端

long_pipeline.py 新增 --mt-backend gguf，进程内加载：

from llama_cpp import Llama   # 延迟导入，不用时不吃内存

llm = Llama(model_path=gguf_path, n_ctx=gguf_ctx, n_threads=gguf_threads, verbose=False)
resp = llm.create_chat_completion(
    messages=[{"role": "system", "content": hint_for(lang)},
              {"role": "user", "content": text}],
    temperature=0.2,
)

必须走 create_chat_completion + Qwen chat 模板。误用 completion 模板会让 7B 自问自答复读。翻译缓存写进 work/<文件名>/mt.json，重跑不重复翻；批量失败会按编号逐条回退。ffmpeg / ffprobe / silencedetect 的 subprocess.run() 一律加 stdin=subprocess.DEVNULL——否则在 IDE/管道环境会卡死。

4.2 启动器：5 行压成 1 行

~/Whisper/local.sh（软链到 /usr/local/bin/wsp）的关键片段：

SRC="${BASH_SOURCE[0]}"
while [ -L "${SRC}" ]; do          # 软链解析：别把「家」认成 /usr/local/bin
  DIR="$(cd "$(dirname "${SRC}")" && pwd)"
  LINK="$(readlink "${SRC}")"
  case "${LINK}" in /*) SRC="${LINK}" ;; *) SRC="${DIR}/${LINK}" ;; esac
done
HERE="$(cd "$(dirname "${SRC}")" && pwd)"
PY="${HOME}/miniforge3/envs/comfy/bin/python"

EXTRA=(--mt-backend gguf)          # 唯一必写的开关，默认 ollama 留给服务器
_wh=0
for a in "$@"; do [ "$a" = "--whisper" ] && _wh=1; done
[ "${_wh}" -eq 0 ] && EXTRA+=(--whisper large-v3)

exec "${PY}" long_pipeline.py "${MEDIA}" "${EXTRA[@]}" "$@"   # 跑完即退

三个设计要点：① 循环 readlink 摸回真实路径，否则从软链启动时找不到模型；② 未传 --whisper 时自动补 large-v3（本机只留这一档）；③ exec 替换 shell，不留后台进程。

chmod +x "$HOME/Whisper/local.sh"
ln -sfn "$HOME/Whisper/local.sh" /usr/local/bin/wsp

五、日常用法与参数旋钮

wsp test-jp.mp3                              # 最简：large-v3 + 7B
wsp "/Volumes/Share/MBRBI-015/xxx.mp4"       # 网络盘素材（空格/日文路径都吃）
wsp test-jp.mp3 --out 我的字幕.srt --batch 8 # 自定义输出与批大小
nohup wsp 大片.mp4 > "$HOME/Whisper/night.log" 2>&1 &   # 挂夜班，跑完自动退

输出 ~/Whisper/<文件名>_双语字幕.srt；缓存 ~/Whisper/work/<文件名>/mt.json 自动断点续跑；词级时间戳、时间轴校准、无对白检测、逐段语种标签默认全开。

想调什么参数说明
换耳朵--whisper large-v3本机只剩这一档；手动传参仍优先
换嘴巴--gguf-model <路径>本机只有 7B；默认位已对准，不必写
CPU 占用--gguf-threads 40=自动；Intel 老机别贪多
内存/吞吐--batch 8默认 15，调小更省内存
时间偏移 / 挂屏--shift 0.2 / --max-sub-dur 5治字幕偏早、偏晚、挂屏
关闭校准--no-refine一般不用
⚠️ 翻译质量没有「加个后缀就变好」的魔法开关——想更准只能换更大的模型（14B/32B），这台 16G Intel 扛不动。

六、踩坑速查表

现象原因与解法
brew install ollama 被 137 掐断Intel/Sonoma 无 bottle，Go 源码编译爆内存。不用装，本机用 GGUF
llama_cpp 导入失败清华源源码包需编译；直接用 comfy 环境
译文复读、自问自答用了 0.5B 或 completion 模板；换 7B + create_chat_completion
从软链启动找不到模型软链解析没做；见 4.2 的 while [ -L ]
卡在「抽取 16k 单声道音频」ffmpeg 监听 stdin；subprocess.run(..., stdin=DEVNULL)
删掉 small 后本地跑找不到模型local.sh 未显式指定时补 --whisper large-v3
日文/SMB 路径取不到字幕macOS SMB 把 じ 存成 NFD 分解形；用「首词前缀 + * 通配」
bash 里中文后面的变量值消失UTF-8 locale 下中文标点被吃进变量名；一律写 ${var}
时间轴挂屏/超前Whisper 段级窗口吞静音；默认词级时间戳 + 校准已修，旧字幕用 srt_refine.py

七、维护与回滚

  • 新增素材：丢进 ~/Whisper/，按文件名自动隔离缓存。
  • 换机器：拷走 GGUF 模型与 local.sh，在 comfy 环境装好 llama_cpp 即可。
  • 回滚到服务器翻译：删掉 /usr/local/bin/wsp 软链，改用 bash long_job.sh 素材.mp4（走 Ollama 千问）。服务器文件从未被本方案改动。
  • 磁盘：模型目录约 8.1G；废纸篓里的 small/turbo 约 2G 清空后才真正释放（Time Machine 本地快照会先 pin 住空间）。
