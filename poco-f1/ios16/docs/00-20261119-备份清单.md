## 三、未纳入备份与已知缺口

- `ios16-root.ssh-fixed.simg`（SHA `43b977c6d3ddccc6208f105c40f9f5`…`35d1af601c`，早期 userspace panic 废弃版）**未复制**；本地 Mac `/Volumes/TARGET/ios16-root-good.simg` 为同件副本。
- **`logo`（splash）分区当前无 dump**：该机 ABL 不支持 `fastboot fetch`，需进 TWRP 用 dd 导出。任何刷写 logo 分区的操作前，必须先补这份备份。
- 上游源码为 GitHub 公开仓库（`ry-diffusion/Bergamota`，main 浅克隆），可重新克隆，未整仓备份；本地工具脚本在 `/Volumes/TARGET/Bergamota-main/tools/`。
- `system` / `vendor` / `cache` / `userdata` 当前安卓残留分区未做整盘 dump；iOS 根只占 userdata 内的 HFS+ 文件系统。

## 四、恢复 / 刷写命令示例

```bash
FB=/Users/tom-mbp162/android-sdk/platform-tools/fastboot
# 临时内存启动 main 对照镜像（不写分区）
$FB -s 2b8c9438 boot kernel-shim/shim/shim-boot.img
# 刷 iOS 根镜像到 userdata
$FB -s 2b8c9438 flash userdata root-images/ios16-root-good-ca3.simg
# 回滚原厂 stock boot
$FB -s 2b8c9438 flash boot boot-recovery/miui-gpt/boot-stock-V12.0.3.0.QEJMIXM.img
# 回滚 TWRP
$FB -s 2b8c9438 flash boot boot-recovery/ofox/twrp-3.7.0_9-0-beryllium.img
```
