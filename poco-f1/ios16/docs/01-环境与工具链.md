## Mac 侧关键事实

- 只装了 **Command Line Tools**（`xcode-select -p` → `/Library/Developer/CommandLineTools`），`/Applications` 下**没有 Xcode**，`iphoneos` SDK 不存在。
  - 因此交叉编译只能 `clang -target arm64-apple-ios16.0 -isysroot $(xcrun --sdk macosx --show-sdk-path)`。
  - `llvm-objdump` 也在 CLT 里，但必须用绝对路径 `/Library/Developer/CommandLineTools/usr/bin/llvm-objdump`。
- 没有 `gh`、没有 `GITHUB_TOKEN` 环境变量；但 **Keychain 里存着 `tomcat080` 的 PAT**（`git credential-osxkeychain get` 可取），所以 `git push` / REST API 都能用，不必在浏览器里逐个上传文件。
- 没有 `timeout`（macOS 无 GNU timeout），没有 `qemu-system-aarch64`。
- 根盘 500G 已用 461G，**只剩约 10G**；大文件一律落外置盘 `/Volumes/TARGET`。
- USB 网卡 `en13`（MAC `02:00:5e:77:ee:01`）每次重启后丢 IP，需重新 `ifconfig en13 inet 192.168.7.1 netmask 255.255.255.0 up`；本机 `sudo` 要密码，走 `osascript … with administrator privileges` 弹窗。

## 设备侧工具分布

| 位置 | 内容 |
|---|---|
| `/usr/local/bin/` | `sweetdur`、`sweetnetcfg`、`sweetprefs`、`sweetps`（电源信息工具，非进程列表）、`sweetreboot`、`hcitest`（本轮自编）、`sh`（minish V3，71,600 B） |
| `/usr/bin`、`/usr/sbin` | `ioreg`、`toybox`、`dropbear` 等 |
| **没有** | `launchctl`、`ps`、`pkill`、`killall`、`log`、`syslog`、`dmesg`、`timeout`、`scp` 子系统 |

由此带来的操作约束：

- 改 `LaunchDaemon` plist 后**无法 `launchctl` 重载**，只能重启让 `launchd` 重读；
- 看不到进程列表，只能用 `ioreg`、`sweetprefs` 和内核日志间接判断；
- 传文件：`ssh 'toybox cat > /path' < 本地文件` + `toybox chmod 755`；
- `minish` 不支持 `for/do/done`、不支持 `exec`。
