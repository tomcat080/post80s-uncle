# USB 枚举打通与固化（2026-11-28）

设备：POCO F1 `beryllium`，fastboot serial `2b8c9438`。

## 根因

ABL 交接后 USB30_PRIM 控制器处于 collapsed/gated：GDSCR 电源域关闭、master/UTMI/PHY/NoC 分支时钟关闭、block reset 未释放。内核里的 SWEET USB 驱动只 probe，不重新上电，所以 PC 上一直不出现 CDC-ECM 网卡。

## shim 修复

`shim/shim.c` 在跳入 XNU 前增加 `usb_power_on()`：

- 打开 GCC USB30_PRIM GDSCR
- 打开 master / mock UTMI / PHY / NoC 分支时钟
- 释放 USB30_PRIM block reset
- 打印 `USBPWR` 和 `USBGSNPSID`

## 镜像

- 实验镜像 `boot/shim-usbpower-20261128.img`，17,346,560 B，SHA256 `31ddd2f4e3103c4307e948b409b56edd00071e9f17aad3f3f18b6fdd7389d37f`
- 固化镜像 `boot/shim-usbpower-stable-20261128.img`，17,362,944 B，SHA256 `ff4f84ff3c1ccb1fa53b6dc7621b9f003360b20135e632d4c5c7e610c0a56d5c`
- 固化镜像 = shim kernel（`0486e599...`）+ `aud_stable.img` 的稳定 payload（`4ba01e13...`，含 `sweetusb=2 sweetwlan=0 sweetwlandelay=0`）

## 真机结果

`fastboot boot` 临时启动：`Sending 16956 KB OKAY [0.462s]`、`Booting OKAY [0.061s]`；约 25 秒出现 `en13`，`192.168.7.1/24`，ping `192.168.7.2` 0% 丢包，SSH 约 60 秒可用（`Darwin iPhone 22.6.0 ... iPhone10,3 Toybox`）。

随后 `fastboot flash boot boot/shim-usbpower-stable-20261128.img`：`Writing 'boot' OKAY [0.074s]`。连续 3 次冷启动都起 `en13`、ping、SSH 和 SpringBoard；`fastboot devices` 为空，确认不是临时启动。

## 用户态 shell

设备原 `/bin/sh` 是旧 minish（71,600 B）。已备份为 `/usr/local/bin/sh.old-20261128`，把 `/usr/local/bin/sh` 换成 minish v3（70,816 B，cksum `2550457892`）。新 SSH 会话验证 `echo`、管道、`&&`/`||`、变量、命令替换、重定向、glob 正常；`for`/`while` 未实现。冷启动后复查仍是 v3，root 持久化通过。

回滚：

```sh
cp -p /usr/local/bin/sh.old-20261128 /usr/local/bin/sh
```

## root-fixed 验证

`root-fixed.simg` 转 20G raw 只读挂载后，镜像为 21.5GB `iOSRoot`（Case-sensitive Journaled HFS+，iPhone OS 16.7.16 / 20H392）。镜像内 `dropbear` SHA256 `875ae9b8...fef6`、`toybox` SHA256 `0629b006...8f18`，与当前设备完全一致，说明当前 root 底包就是它，不需要再刷 12G userdata。

## 结论

USB 枚举已在 boot 分区固化；以后换 boot 仍先 `fastboot boot` 验证，再 `flash boot`。音频/WiFi 仍封存：音频缺口是 AOP QMP `load_state on` + `scm_pas_enable_bw()` NoC/EBI 带宽票，不要重复 stage33–43 刷机。
